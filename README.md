# Momentum v1
Open index.html in a desktop browser for a local preview. For Android installation, upload all app files to a GitHub Pages repository (HTTPS), open its Pages URL in Chrome, and use Install app or Add to Home screen. Open once online before offline use. Export backups from Settings. Browser storage is not a guaranteed backup. No account or server sync. Schedule edits reinterpret historical completions; weekly streaks count Monday–Sunday including the first partial week. Archive preserves completions but does not pause streak calculations. History is read-only. Run `node test.js` for streak tests if Node is available. For future updates, change the cache version in sw.js. Android installation and UI have not been device-tested.
